## Files

Your memory is the workspace: markdown files to look through and write. Paths are relative to the workspace root (`MEMORY.md`, `people/ana.md`). `search` finds things across everything by what they're about; `grep` finds an exact phrase inside files; `find` lists files by name pattern; `read` opens one. A `read` with `limit: 100` keeps it short, and `grep` first finds the right place in a long file.
